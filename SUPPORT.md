# Get help using Simar

Start with the [one-page guide](README.md#start-here) and [detailed installation instructions](INSTALL.md).

## Ask a setup question

Open a [help issue](https://github.com/simarjeetkhosa/Simar-Canadian-Immigration/issues/new?template=help.yml). Include your AI application and version, operating system, installation method, exact error and what you expected. Share a small fictional example if needed.

Before posting, confirm that both Simar skill folders contain SKILL.md, refresh the host's skills list, and try the blank case-audit prompt in the README. A file attachment alone is not an installed skill. Web access, Adobe tools and scheduling are separate host capabilities.

## Report problems or suggest improvements

Use the [bug report](https://github.com/simarjeetkhosa/Simar-Canadian-Immigration/issues/new?template=bug.yml) or [feature request](https://github.com/simarjeetkhosa/Simar-Canadian-Immigration/issues/new?template=feature.yml) form. To help improve the project, read [CONTRIBUTING.md](CONTRIBUTING.md).

## Keep case information private

GitHub issues and pull requests may be public. Do not post client records, government identifiers, account credentials, private case histories or unredacted screenshots. Use invented examples and redact errors before sharing them. This help channel is for the software and workflows; case-specific legal advice and urgent deadlines need an appropriate professional channel.

Community help is welcome. Response times and support across every AI platform are not guaranteed.
