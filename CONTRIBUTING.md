# Contribute to Simar Canadian Immigration

Contributions are welcome: clearer installation steps, reproducible bug reports, accessible wording, Punjabi/English improvements, corrected references and tested compatibility with additional AI agents.

## Propose an improvement

1. Search existing issues to avoid duplicates.
2. Open an issue describing the problem, your AI application/version, and the expected result. Use fictional examples.
3. For a code or documentation change, fork the repository, create a branch, and keep the change focused.
4. Submit a pull request explaining what changed, why, and how you checked it. Maintainer review is required before changes are merged.

You can contribute without writing code: report a confusing instruction, propose a better example, or share a platform setup that you actually tested.

## Quality expectations

- Preserve the complete skill folder structure and keep instructions consistent with the installer and MCP server.
- Support immigration-policy or legal-reference corrections with dated primary-source links. Clearly distinguish verified information from a proposal.
- Describe platform compatibility as tested only when you actually tested it; include the product and version.
- Use synthetic data. Do not include client documents, passport numbers, application identifiers, credentials, or other private information in issues, commits or screenshots.
- Preserve LICENSE and NOTICE.md. Contributions are submitted under this repository's MIT License.
- Treat the original v1.0.0 ZIP as a historical release. For a new release, regenerate its archives and checksums together.

## Check your change

For documentation, check links, commands and agreement with the current product documentation. For installer or server changes, use an isolated environment and run the relevant existing tests described in INSTALL.md. Include the results and any limitations in your pull request.

## Review and help

Maintainers may ask for changes or clarification. Please discuss the work respectfully and give actionable feedback. For setup questions, see SUPPORT.md. This project does not promise response times or individual immigration advice.
